# Surfaces

Pipes are processes. Surfaces are the files a later agent will actually touch.

A pipe break often has a surface cause. Example: AR last mile is a pipe function. The missing send is a Catalog/Grant surface. The missing World is a Roster surface. The “outbox / preview” sentence is a Skill surface.

Read the pipe file first. Then read the surfaces that file names.

| Surface | Typical edits | Typical failure categories |
| --- | --- | --- |
| BOT.md | Identity, object, must-not, done-when, handoff protocol | T1, T6, T7, T8 |
| Skills | Judgment remainder, not Kernel replay | T6, T7 |
| Grants / Catalog | Ops the Profile may call | T3, T9 |
| Harness protocol | Bind, Handle, cwd, extra `-e` | T5, T9 |
| World / inbox | Simulated mailbox | T1, T2, T4 |
| Verifiers | Concurrence owner | T9 |
| Memory | Next-period change | T10 |
| Wakes / Routines | How work starts | T5 |

Do not “fix AR” by only rewriting `ar-collections-policy`. That is T7 theater if send still does not exist.
