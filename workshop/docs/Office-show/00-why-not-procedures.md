# Why procedures are not the demo

Billy’s question: can I run all the procedures, maybe on one instance, and that *is* the demo?

**No.** Procedures validate. The show is a different run on a different Computer.

---

## What a procedure is for

A prove step exists to **cover a door**.

It names a Catalog op. It names HARD vs SOFT. It may Wake `collect` and tell it to call `create_accrual` so the Grant door refuses. That is correct QA. It is poison on a demo tape.

P6 loads leftover skills with “call list_mail_documents.” P7 fills remainder ops. P0 smokes `get_company_policies`. P9 is Kernel eval. None of that is “the office had a Tuesday.”

If those Wakes sit in `protocol.jsonl`, the Demo page will replay them. There is no filter that says “hide QA.” Record copies the protocol as it is (`POST /api/demo/record` → `harness/demo/latest/protocol.jsonl`).

---

## Same instance?

| Idea | Why it fails |
| --- | --- |
| All procedures on one Computer, then Record | Tape contains QA Wakes, SoD negative tests, forced Catalog calls, CHECKPOINT language |
| Each procedure on its own instance, then “the demo is that they all passed” | True as a **lab report**. False as a **show**. No single identity crossed AP → pay → cash → close |
| Reuse `prove-…-month-r1` as golden because P1–P5 already ran | Closest trap. That month still has prove Wakes in protocol. Scrubbing them by hand is a lie. New instance |
| Run procedures *silently* (no protocol) then show Kernel state | The judged proof is Pi RPC and Handles, not a Python ending. Empty protocol is a chatbot with a stuffed GL |

Prove **month** instance is allowed to look like a pipe. It is still a test. Do not record it for judges.

---

## What judges (and a HackMIT reel) actually see

Harness Demo (Tools → Demo) is the showcaser. It:

- Reads `protocol.jsonl` plus per-Bot transcripts
- Slides a playhead from wipe (seq 0) forward
- Spawns mosaic panes for awake Bots

Whatever you said to a Bot is a line in that slider. “profile: prepare / Call tools.get_invoice / Do not approve” is a line. “September inbox landed. Classify. Bills to AP. Remittances to apply. Ignore quotes.” is a different line.

The second sentence is the office. The first is the lab.

---

## Nuance: prove still earns the show

You do not skip prove. If send still ImportError, the golden collect chapter will HARD on minute one. If intercept default is Operator, the golden pay-run will park on a human. If BOT.md is missing from Computer cwd, every Bot will wander.

Prove answers: *can* this office live a month.
Show answers: *here is* the month.

Bare-min prove (RUNS, holes named) can still produce a smaller show: featured Acme + `$12.40` BLOCKED, skip collect send if T3. Demo-ready prove (INTENDED) produces the full calendar. Do not wait for P7 remainder ticks to start a golden run if pipes P0–P5 are INTENDED. P7 is coverage, not plot.

## What changes in manner (prove vs show)

| | Prove | Show |
| --- | --- | --- |
| Instance | many, disposable | one, preserved |
| Wake language | name the op | name the open item |
| Forced Catalog | yes (P7) | never |
| SoD negative test | yes (P0 S07) | never on tape |
| Classification | every step HARD/SOFT | abort on throw; do not log SOFT into protocol |
| Skill edits | after procedure | not during golden |
| Operator | test Wake allowed | overlay only, almost silent |
| Routines | fire to tick a row | fire because it is Friday / month-end |
| Record | optional | required at the end |
| Wipe | on HARD | never after a good chapter; abort whole goose instead |

---

## “If it works through all of this, that shows it can do everything”

That sentence is true as **validation**. It is not true as **presentation**.

A lab that called every tool is the wrong movie. The right movie is one company, one September, Bots handing work to Bots, close refusing to lie about twelve dollars and forty cents.

The portfolio object is that movie’s recording, plus the instance you can still open.
